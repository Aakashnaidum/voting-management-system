# Provenance and Attribution

This file records what is known about the origin of this repository and what should not be inferred from it.

## Source status

The project began from a third-party academic project package that was shared by a classmate. The exact upstream repository, download page, vendor, and license terms are not currently known.

Because the original redistribution rights are unresolved, this repository should be treated as a portfolio and review artifact, not as an open-source project that grants reuse rights.

## What came from the base project

The base package provided the broad project idea: a Java web application for a voting-management workflow with administrators, voters, candidates, nominations, voting, and results.

The original package is not represented here as wholly original work by Aakash Naidu.

## What this repository contributes

This repository presents a revised and documented version focused on safer educational web-application design:

- password hashing instead of plaintext or default credentials
- role-based access checks
- CSRF protection
- parameterized SQL
- transaction-backed duplicate-vote prevention
- clean schema and synthetic demonstration data
- tests and CI checks
- security review notes and educational limitations

## Publication limits

No open-source license is granted at this time. Do not assume that the original project package, old assets, or derived material may be reused outside review of this portfolio repository.

This project is educational. It should not be described as election-grade software, audited security software, or a production voting system.

If the upstream source and license are later identified, this file should be updated with exact links, license text, and any required attribution.
